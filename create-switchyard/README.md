# create-switchyard

Run `npx create-switchyard` from the root of a git repo to add [Switchyard](https://github.com/nicoleman0/switchyard) to it.
It needs git, Python 3, and Node.js 18 or later.
The package holds one release and works offline. See the [main README](https://github.com/nicoleman0/switchyard#add-it-to-an-existing-repo) for what install does.
